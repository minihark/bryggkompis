# Bryggkompis 🍺

> **Receptplanerare & Ölkompaniet Kalkylator** för hembryggare som vill planera, beräkna och brygga öl tillsammans.

Byggt för Viktor och hans bror-i-lag med ingredienser härledda direkt från [Ölkompaniet.se](https://www.olkompaniet.se/).

## Funktioner

- **Idé- & Stil-Studio**: Välj bland 8 beprövade ölstilar (Göteborgs Västkust-IPA, Disig Haze-Bomb NEIPA, Skärgårdspilsner, Bror-i-lag Session Pale, Höststout, m.fl.) eller slå med idé-tärningen!
- **Realtidsberäkningar**:
  - **OG (Stammört)** baserat på mäskeffektivitet och maltsort.
  - **FG (Slutdensitet)** baserat på jästens utjäsning (attenuation).
  - **Alkoholhalt (ABV)**: `(OG - FG) * 131.25`.
  - **Beska (IBU)** beräknat med Glenn Tinseth-formeln för varje humlegiva (kok, whirlpool, torrhumling).
  - **Färg (EBC / SRM)** med Morey-formeln och dynamiskt interaktivt ölglas med stigande kolsyrebubblor och skumkrona!
  - **Vattenkalkylator**: Beräknar exakt mäskvatten (strike water) och lakvatten (sparge water) i liter.
- **Inköpslista Ölkompaniet**: Summerar ihop receptet till butiksförpackningar (1kg / 5kg malt, 100g humlepåsar, jästpåsar) med direktlänkar till Ölkompaniet.se och estimerat pris i SEK.
- **Bryggdagsprotokoll**: Interaktiv steg-för-steg checklista med inbyggd nedräkningstimer för koket.
- **Tvåspråkigt**: Snabbväxling mellan 🇸🇪 Svenska och 🇬🇧 Engelska.
- **Taktilt ljud**: Äkta Web Audio-syntes för kapsylöppning (`tssk!`), skål-klirr och kolsyrebubblor.
